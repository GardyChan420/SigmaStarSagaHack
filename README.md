Patches for hacks on Sigma Star Saga (GBA).

1. Sigma Star Saga NGPlus Stat Mulithack

   It is a hack that adds more benefit to NGPlus by adding multipliers to level-up stat increased. For each NG+ it will add 1, up to 10x multiplier. Also I increased the stat cap for atk and def to 999 by using code caves to inject code to do so as the hard system cap is like, 138 if the data is signed and 266 if not. At most, in vanilla you can have max 110 atk 100 def on Level 99, and yes, flat stat raise I know. Hence I add some flavor to the boring NG+ kek
